ℹ️ About This Project

What we built, why, and how.

❓ Problem Statement

NASA's SPHEREx telescope produces huge amounts of infrared sky data in FITS files, a format that ordinary users cannot open or understand. Finding objects that move between observations by hand is slow, and the idea of a hidden "Planet X" is hard to explore without tools.

✅ What We Solved

  • Converted raw FITS data into images anyone can view
  • Built a web explorer for regions, bands and dates
  • Automatically detected objects that change between observations
  • Built a gravity simulator to test how a Planet X could affect distant objects
  • Added a satellite tracker, a space weather monitor and an AI assistant

🪐 What is Planet X?

Planet X (also called Planet Nine) is a hypothetical planet far beyond Neptune. It was proposed because some distant objects, like Sedna, have orbits that look pulled in the same direction.

It has not been confirmed. Our simulator is a scientific model, not proof that Planet X exists.

⚙️ Backend

  • Node.js with Express (server.js)
  • csv-parse to read NASA archive responses
  • Python for image processing: astropy, numpy, matplotlib, scipy, reproject
  • Data: NASA IRSA (SPHEREx), NASA JPL, CelesTrak, NOAA
